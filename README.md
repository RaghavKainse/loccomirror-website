# Locco Mirror — Official Landing Website

> Real-time USB screen & uncompressed 48kHz audio mirroring from Android to Windows with ultra-low latency (<10ms) and Direct3D 11 GPU hardware presentation.

## Features
- **Instant Downloads**: Windows 64-bit installer (`.exe`) and Android client (`.apk`).
- **Simple Setup Guide**: Step-by-step connection instructions for Direct USB (AOA 2.0) and USB Debugging (ADB).
- **Core Performance Engine**: Highlighted 4K up to 120 FPS, Direct3D 11 hardware decoding, <2% CPU usage, and OBS Studio compatibility.
- **Modern Responsive Design**: Built with React 19, Vite, Lucide Icons, and GSAP animations.
